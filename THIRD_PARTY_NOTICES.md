## ggml / llama.cpp

The codebook tables of the GGUF "IQ" weight formats in `src/quant_tables.*` are generated by
`tools/gen_quant_tables.py` from `ggml/src/ggml-common.h` of llama.cpp. The readers for the GGUF
weight formats in `src/engine.mm` and `src/kernels_quant.metal` were written for this project
but follow the format definitions of the same file. The small test prompts in `ref/data/` quote
llama.cpp's README. No other llama.cpp or ggml code is used; `ref/tools/ref_logits.cpp` links
llama.cpp only as an external reference for validation and is not part of the server.
